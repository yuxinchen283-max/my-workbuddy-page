## 如何测试

### 测试1: 向左挥左手
1. 抬起左手，向左挥动
2. 观察视频小窗是否显示 "◀ 左挥"
3. 观察控制台是否输出 "检测到左手向左挥！"
4. 观察调试面板中"向左挥手"是否显示 "是 ✓"
5. 观察游戏中的角色是否左转

### 测试2: 向右挥右手
1. 抬起右手，向右挥动
2. 观察视频小窗是否显示 "右挥 ▶"
3. 观察控制台是否输出 "检测到右手向右挥！"
4. 观察调试面板中"向右挥手"是否显示 "是 ✓"
5. 观察游戏中的角色是否右转

### 测试3: 向上挥手
1. 抬起左手或右手，向上挥动
2. 观察视频小窗是否显示 "▲ 上挥"
3. 观察控制台是否输出 "检测到左手/右手向上挥！"
4. 观察游戏中的角色是否加速

### 测试4: 握拳刹车
1. 弯曲手肘，握拳（手腕靠近肘部）
2. 观察视频小窗是否显示 "✊ 握拳刹车"
3. 观察控制台是否输出 "握拳刹车中..."
4. 观察游戏中的角色是否刹车停止
5. 松开拳头，观察是否恢复前进

## 如果检测不到

### 可能的原因和解决方案

#### 1. 方向反了
**症状**: 向左挥手，但显示"右挥"

**解决方案**: 修改 `detectWave()` 中的方向判断
```javascript
// 第434行，将 < 改为 >
if (velX > -PARAMS.waveVelocityThreshold) {  // 原来是 <
  leftWave = true;
}
```

#### 2. 阈值还是太高
**症状**: 控制台显示速度值，但不触发手势

**解决方案**: 进一步降低阈值（第145-147行）
```javascript
waveVelocityThreshold: 0.02,   // 从 0.05 降低
waveUpVelocityThreshold: 0.05,  // 从 0.08 降低
```

#### 3. 速度计算错误
**症状**: 速度值始终为 0 或很小

**解决方案**: 检查 `processLandmarks()` 中的顺序
- 确保第517行（`detectWave()` 调用）在第528-538行（`prevLeftWrist` 更新）之前
- 检查 `dt` 是否在合理范围内（0.01 到 0.5 之间）

#### 4. flipHorizontal 参数错误
**症状**: 所有方向都反了

**解决方案**: 修改第719行的 `estimatePoses()` 参数
```javascript
const poses = await detector.estimatePoses(video, { flipHorizontal: false });  // 改为 false
```

## 参数调整

在代码的第137-148行，可以调整这些参数：

```javascript
const PARAMS = {
  waveVelocityThreshold: 0.05,   // 左右挥手速度阈值（降低更容易触发）
  waveUpVelocityThreshold: 0.08,  // 向上挥手速度阈值（降低更容易触发）
  fistDistanceThreshold: 0.25      // 握拳距离阈值（提高更容易触发）
};
```

**建议**:
- 如果检测不到手势 → 降低 `waveVelocityThreshold` 和 `waveUpVelocityThreshold`
- 如果误触发太多 → 提高 `waveVelocityThreshold` 和 `waveUpVelocityThreshold`
- 如果握拳检测不到 → 提高 `fistDistanceThreshold`
- 如果误触发握拳 → 降低 `fistDistanceThreshold`

## 常见问题

### Q1: 为什么视频中的我是镜像的？
**A**: 这是正常的。`flipHorizontal: true` 会将视频镜像，这样你的动作和屏幕上的骨骼显示是一致的（就像照镜子）。

### Q2: 为什么手势检测有时会失灵？
**A**: 可能的原因：
1. 光照不足，MoveNet 检测不到骨骼
2. 动作幅度太小，速度没超过阈值
3. 身体部分被遮挡

### Q3: 如何知道 MoveNet 是否正常工作？
**A**: 观察视频小窗：
- 如果看到骨骼线，说明 MoveNet 正常工作
- 如果显示"等待人体检测..."，说明置信度太低
- 查看调试面板中的"置信度"，如果 > 30% 说明正常工作

### Q4: 握拳刹车的原理是什么？
**A**: 检测手腕是否靠近肘部。当手腕和肘部的距离小于 `fistDistanceThreshold` 时，判定为握拳。

### Q5: 如何调整灵敏度？
**A**: 修改第137-148行的参数：
- 降低 `waveVelocityThreshold` → 更容易检测左右挥手
- 降低 `waveUpVelocityThreshold` → 更容易检测向上挥手
- 提高 `fistDistanceThreshold` → 更容易检测握拳
